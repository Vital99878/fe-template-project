# shared/ui/blocks

Универсальные составные UI-блоки.

Цель: не смешивать примитивы (`shared/ui`) с компонентами,
которые уже собирают несколько примитивов и задают UX-поведение.

## Что хранится здесь

Блоки, которые:

- собирают 2+ примитива (например Button + Text + Icon)
- имеют готовый layout/поведение
- не зависят от домена (иначе это уже `widgets/` или `features/`)

Примеры :

- `ErrorScreen` (экран ошибки: заголовок/описание/кнопки)
- `PageQueryGuard` (обёртка поведения страницы: loading/throw error)

## Что НЕ хранится здесь

- бизнес-компоненты конкретной фичи
- компоненты, которые завязаны на конкретный API/registry/query
- “маленькие” примитивы (для них есть `shared/ui`)
