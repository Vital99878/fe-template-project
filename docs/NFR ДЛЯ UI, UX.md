# NFR ДЛЯ UI, UX

## Focus trap

### Button, Input, Field — сразу заложить:

- единый стиль focus-visible

- хороший контраст

- offset (чтобы рамка не “слипалась” с границей)

Тогда во всём проекте будет правильная клавиатурная навигация.

### Мини-чеклист “Tab куда надо” (повесь в проект)

- Все интерактивные элементы доступны с клавиатуры

- Видимый :focus-visible

- Диалоги трапят фокус

- После закрытия фокус возвращается

- Esc закрывает модалку

- Нет фокуса на скрытых элементах

- Не используем div onClick вместо button
